Motivation

GLIDE-Net is a community-driven open data network for gas–liquid two-phase flow research, aiming to provide high-quality and reusable benchmark data resources for CFD and machine learning. Publicly available data in gas–liquid two-phase flows are still relatively scarce, especially datasets that are systematically organized, well standardized, and easy to reuse. Existing data are often scattered across papers, research groups, and personal repositories, which increases the difficulty of data access, comparison, and reproducibility.

To address this need, GLIDE-Net is dedicated to aggregating multi-source data from numerical simulations and experimental studies, covering representative problems such as droplets, bubbles, breakup/coalescence, jets, films, and typical gas–liquid flow regimes. The platform emphasizes metadata standards, variable consistency, dataset cards, and usage guidance, with the goal of transforming fragmented data resources into an open, searchable, citable, reusable, and AI-ready data infrastructure.

These resources can support a wide range of tasks, including super-resolution, spatio-temporal forecasting, flow-regime identification, model correction, closure modeling, and CFD–ML coupling. Through open data and community collaboration, GLIDE-Net aims to help shift gas–liquid two-phase flow research from isolated data accumulation toward systematic benchmark construction, thereby promoting more reliable and efficient data-driven scientific research.

Distribution

The platform is designed for lightweight and efficient data link management. It aggregates domestic and international sources so users can find, download, cite, and reuse gas-liquid two-phase datasets. Our CFD or ML resources are shared via GitHub ModuleScope and Kaggle. Specifically, code is shared via GitHub, while data and models are shared via ModuleScope, Kaggle, Zenodo, or institutional repositories. To download dataset via Kaggle or ModuleScope, you can refer to the tutorials. Summaries of the data are available here!
