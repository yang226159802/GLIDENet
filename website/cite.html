Cite

Please cite GLIDENet and the individual dataset records when using catalogue metadata, preview figures, links, loaders, or benchmark definitions.

Current Publications

A formal GLIDENet publication and DOI will be added when available. Until then, cite the website repository and the individual dataset page used in your work.

@misc{glidenet,

}

Related Publications

Related papers and dataset-specific citations will be listed as dataset records are accepted.

Single Dataset Citation

When using a specific dataset, cite the original authors, DOI or related paper when provided, the hosting platform record, and the GLIDENet dataset page.

License

Each dataset keeps its own license. The catalogue page reports the license declared by the dataset provider. Users are responsible for following dataset-specific reuse terms.
