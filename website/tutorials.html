Tutorials

These tutorials explain how to browse, upload, download, and package GLIDENet datasets using ModelScope, Kaggle, and standard metadata files.

Quick-start

Browsing Data

Use the Datasets page to inspect preview images, case counts, metadata, license information, and links to external hosting platforms.

Dataset Download

Small datasets can usually be downloaded through the hosting platform's web interface. Large datasets should be downloaded with Kaggle CLI, KaggleHub, ModelScope SDK, ModelScope CLI, or Git LFS.

Using Local Workstations or Clusters

For cluster uploads, prepare credentials carefully and verify network access to the target host before starting large transfers.

Kaggle Command Line API

Install Kaggle CLI with Python and configure credentials before uploading or downloading datasets.

python3 -m pip install --user --upgrade kaggle
mkdir -p ~/.kaggle
chmod 700 ~/.kaggle
mv kaggle.json ~/.kaggle/kaggle.json
chmod 600 ~/.kaggle/kaggle.json
kaggle datasets list -m

A Kaggle package should include `dataset-metadata.json`, `info.json`, `README.md`, `load_example.py`, `checksums.sha256`, and `data/` when possible.

kaggle datasets init -p <path/to/dataset>
kaggle datasets create -p . -r tar -t
kaggle datasets download -d <owner>/<dataset-name> --unzip

KaggleHub and cURL Download

KaggleHub can download datasets from Python after credentials are configured through interactive login, environment variables, or `~/.kaggle/kaggle.json`.

import kagglehub

kagglehub.dataset_download("<owner>/<dataset-name>")
kagglehub.dataset_download("<owner>/<dataset-name>", path="data.csv", output_dir="./data")

cURL can also be used for direct API downloads when username and API key are available.

ModelScope Upload and Download

ModelScope is recommended for China-accessible dataset hosting. Create a dataset repository, prepare `README.md`, `info.json`, and `data/`, then upload through Git, Python SDK, CLI, or the web interface.

git lfs install
git clone https://www.modelscope.cn/datasets/<namespace>/<dataset-name>.git
git lfs track "data/*"
git add .gitattributes .
git commit -m "Upload dataset"
git push
modelscope login --token YOUR_MODELSCOPE_TOKEN
modelscope upload owner_name/repo_name /path/to/your_folder --repo-type dataset
modelscope download --dataset <namespace>/<dataset-name> --local_dir ./data

Reading Solver-specific Binary Data

For extensionless or solver-specific files such as `Gvol.000001`, `V.000001`, and `P.000001`, metadata must document header bytes, dtype, endianness, payload shape, vector component order, reshape order, units, grid, and field location. A tested `load_example.py` is mandatory.
